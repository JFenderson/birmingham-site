# UI/UX Skill Pack

These skills are designed for product-focused frontend work in this repository.

## Skills

- design-system-enforcement: Keep design tokens, spacing, and component usage consistent.
- accessibility-audit-ui: Run practical WCAG-focused accessibility audits.
- app-router-ux-patterns: Standardize loading, empty, success, and error states in Next.js App Router.
- role-based-ux-maps: Define role-specific visibility and action permissions in UI.
- form-ux-validation: Build reliable validation, error, and recovery states.
- mobile-first-qa-checklists: Verify responsive behavior with repeatable QA checklists.
- interaction-copy-microcopy: Improve labels, helper text, and confirmations.
- usability-smoke-testing: Run short scenario-based UX smoke tests after each feature.

## Usage pattern

When asking an agent for UI work, mention the skill name explicitly in your prompt:

- "Use `design-system-enforcement` while implementing this page."
- "Apply `accessibility-audit-ui` before finalizing."

## Notes

- Keep each skill focused on one concern.
- Prefer updating existing skills over creating near-duplicates.
- Keep checklists actionable and testable.
