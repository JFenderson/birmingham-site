# interaction-copy-microcopy

Use when improving short UI text such as labels, helper text, confirmations, and status messages.

## Use this skill when

- Buttons or labels are ambiguous.
- Error/success messages are generic or technical.
- Destructive actions need safer wording.

## Goals

- Increase clarity and trust.
- Reduce decision friction.
- Keep language concise and actionable.

## Checklist

1. Use verb-first button labels for primary actions.
2. Keep helper text specific to the user's next action.
3. Ensure error copy explains what to do next.
4. Confirm destructive actions state impact clearly.
5. Avoid jargon and internal system terms.
6. Keep tone consistent across portal and public UI.

## Output format

- Before/after microcopy set.
- Rationale by user intent and risk level.
- Priority list of high-impact copy changes.

## Anti-patterns

- Vague labels like "Submit" or "Continue" without context.
- Technical backend error strings shown directly to users.
- Overlong paragraphs in transactional UI contexts.
